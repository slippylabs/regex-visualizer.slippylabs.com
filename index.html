REGEX VISUALIZER

See what a regular expression actually is — a machine. Type a pattern, watch it compile into a state graph, then step a string through it one character at a time.

This builds a Thompson NFA: every construct becomes a little sub-machine wired together with epsilon transitions (drawn as ε), which is why the state count grows faster than the pattern length. Simulation tracks the whole set of states the machine could be in at once — that set is the reason an NFA needs no backtracking. Matching is anchored at both ends, as if the pattern were wrapped in ^(?:…)$, and every verdict is cross-checked against the browser's own regex engine; the two must agree. Supported: literals, ., character classes with ranges and negation, \d \w \s \D \W \S, groups, alternation, * + ? and {n,m}. Backreferences, lookaround and lazy quantifiers are not — they are exactly the features a plain NFA cannot express.
